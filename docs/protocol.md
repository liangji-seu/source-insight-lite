# Engine protocol v1

Transport: UTF-8 newline-delimited JSON on stdio. One request per line: `{"id":1,"method":"index","params":{...}}`; response `{"id":1,"result":...}` or `{"id":1,"error":{"message":"..."}}`. Notifications: `{"method":"progress","params":{"completed":10,"total":100,"file":"..."}}`. stdout contains protocol only; logs go to stderr. Engine launched `python -u backend/run.py --db <absolute cache path>`; do not import/execute scanned source. Paths absolute, lines 1-based. IDs stable strings.

Symbol: `{id, kind, name, qualifiedName, file, startLine, endLine, parentId, moduleId, details}`. Kinds: module, class, method, function, member, constant. `parentId` null for modules; nested items refer to enclosing symbol. `details` object can include docstring, bases, decorators, parameters, returnAnnotation, inferredType, imports.

Relationship: `{sourceId, targetId, type, status, confidence, label, file, line}`. targetId nullable when unresolved. type: imports, inherits, owns, calls, overrides; moduleGraph also synthesizes contains edges. status: resolved, inferred, unresolved, dynamic; confidence: high, medium, low. Never resolve by globally matching a bare method name. Unresolved references remain visible as evidence.

Methods:
- `index {root, excludes?:string[]}` -> `{root, files, symbols, relationships, errors:[{file,message}], elapsedMs}`. Atomic replacement; persist root and summary. Exclude defaults: .git, .venv, venv, node_modules, build, dist, __pycache__, site-packages, third_party, vendor. Full reindex only MVP.
- `summary {}` -> last index summary or null.
- `symbols {kind?:string, parentId?:string, query?:string, file?:string, limit?:number, offset?:number}` -> `Symbol[]`. Query substring name/qualifiedName; `file` is an exact absolute path filter (case-insensitive on Windows). Default limit 1000; requested capped 10000. Omitted parentId means all. UI must avoid presenting a capped result as complete.
- `inspect {id}` -> `{symbol, children:Symbol[], outgoing:Relationship[], incoming:Relationship[], related:Symbol[]}`; related contains known endpoints.
- `context {file,line}` -> most deeply nested containing Symbol or null.
- `graph {id, types?:string[], direction?:"in"|"out"|"both", depth?:number, limit?:number}` -> `{nodes:Symbol[],edges:Relationship[],truncated:boolean}`; depth 1..3, limit default 100 max 300. Include focused symbol even isolated; preserve unresolved edges with null endpoints for textual display.
- `moduleGraph {id, depth?:number, limit?:number}` -> `{nodes:Symbol[],edges:Relationship[],truncated:boolean}`; depth 1..3, limit default 80 max 300. Nodes are module-kind records. `id` accepts a real module symbol ID or a synthetic package ID `package:<qualifiedName>`. Missing Python package `__init__.py` files become synthetic package nodes with `details.isPackage=true` and `file:""`; package nodes show direct `contains` children. Resolved imports and calls are aggregated by source/target module with labels `导入 ×N` or `调用 ×N`; unresolved evidence remains an edge with `targetId:null`.
- `classGraph {id?:string, file?:string, depth?:number, limit?:number}` -> `{nodes:Symbol[],edges:Relationship[],truncated:boolean}`; supply a class symbol ID or an absolute source file path. A file focus includes all classes in that file. Depth is 1..3 and limit defaults to 80, capped at 300. Nodes are full class records. Inheritance and calls are aggregated between nearest owning classes; call labels include up to three target method names and the evidence count. Class-local calls are omitted, while module-level or unresolved targets remain unresolved with `targetId:null`. Known endpoints are bounded to returned nodes.
- `explainContext {id}` -> `{symbol, context:string}` structured bounded explanation prompt, no AI request.
- `shutdown {}` -> true and graceful exit.

Extension owns per-workspace database in VS Code globalStorageUri, starts backend only in trusted file workspace. Python executable configurable (single executable path, shell false); Windows default python, macOS default python3. Bundle backend with extension during build into extension/backend. Configure excludes in VS Code. AI interface optional, no provider implementation/key required for MVP; export/copy structured explanation context. The UI may use symbol, module, and class graph modes for their respective scopes. Cytoscape local bundle preferred. No CDN. HTML escaping, nonce CSP, validate webview message symbol IDs against backend before opening files.
