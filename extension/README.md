# 源码架构探索器

快速了解 Python 模块的类、属性、方法，以及它们被哪些类调用。中文界面，源码实现按需打开。

## 开始阅读

1. 在新的 VS Code 窗口点击左侧“源码架构”图标。
2. 点击“选择源码目录”，把目标项目作为工作区打开。
3. 点击“解析”，等待完成。
4. 从左侧“文件”打开源码，“当前文件结构”随文件切换，显示类、成员属性、方法参数和返回类型。
5. 点击“类关系”，查看当前文件中各个类的调用和继承关系。连线标出被调用的方法；选中类自动显示属性和方法概览。
6. 点击“模块关系”，查看包对模块的包含，以及模块之间的导入、调用关系。

关系图默认展示附近一层，最多 80 个节点。选中节点后可“以此为中心”继续探索；需要追实现时再点击“查看源码”。虚线表示静态推断，未确定关系单独列出。再次打开已解析项目会读取本机缓存；源码改变后点击“重新解析”。

## 运行要求

- VS Code 1.90 或更高版本。
- Python 3.10 或更高版本，建议 3.12+。如找不到 Python，在设置中填写 `architectureExplorer.pythonPath`。
- 当前支持本地 Python 源码。文件树可打开其他语言文件，但不会为其生成类关系。

分析引擎只解析源码，不运行目标项目。阅读 vLLM 不需要 CUDA、GPU、PyTorch 或安装 vLLM 依赖。索引写入扩展本地存储，不修改所阅读的源码，也不会自动上传源码。

## 分析边界

调用和类型信息来自静态分析，动态派发、猴子补丁及运行时导入无法完整确定。方法概览显示解析到的参数及类型，不保证还原全部动态接口语义。包层级来自源码结构，不代表自动推断的业务架构。

Windows 优先验证；macOS 使用跨平台实现，尚未实机验收。此版本没有增量解析、C/C++/CUDA 分析或付费 AI 请求。
